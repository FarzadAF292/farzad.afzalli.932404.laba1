## Описание

Проект представляет собой веб-страницу «О себе», созданную с использованием HTML и CSS.

На странице реализованы:

- шапка с информацией о студенте;
- секция «Навыки»;
- секция «Проекты»;
- боковой блок с описанием подхода к бизнесу;
- изображение профиля;
- форма обратной связи;
- подвал страницы;
- оранжево-белая цветовая гамма.

## Используемые технологии

- HTML5
- CSS3

## Проверка

HTML-код страницы проверен с помощью W3C Validator.
